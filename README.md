# 🚔 СР УГИБДД — Методичка по отыгровкам

> Полное методическое пособие для сотрудников Специализированной роты УГИБДД в Roleplay игре **Amazing Online**

---

## 📖 Содержание

### Основные разделы методички
- 📌 **Введение** — цели, задачи и функции СР УГИБДД
- 🏛️ **Структура и должности** — иерархия подразделения
- 👤 **Портрет сотрудника** — личностные качества, навыки, подготовка
- ⚖️ **Законодательная база** — УК, КоАП, ФЗ №3, ФЗ №1, Конституция, Порядок надзора, ПДД
- 📚 **Юриспруденция** — основные понятия, виды НПА, применение в работе
- 🔗 **Уголовное право** — общая и особенная части УК РФ
- 📖 **Глоссарий** — основные термины

### Практические разделы (примеры)
- 🚑 **Первая помощь** — обморок, кровотечения, переломы, пулевое, обморожение
- 🚗 **Оформление ДТП** — полный порядок действий
- 💣 **Разминирование** — СВУ через /try и /do, таймер
- 🪢 **Растяжка** — обезвреживание натяжных устройств
- 🔫 **Штурм** — группы, виды, тактики
- 🤝 **Переговоры** — цели, обязательные действия, запреты

### Дополнительно
- 📋 **Состав** — таблица личного состава СР УГИБДД

---

## 🛠️ Технологии
- HTML5, CSS3 (адаптивный дизайн, тёмная/светлая тема)
- JavaScript (частицы, вкладки, анимации, копирование кода)
- Google Fonts (Outfit, Unbounded)
